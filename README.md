## 软件介绍

tsrbox 是一款本地 3D 模型资源管理桌面应用，支持 Blockbench `.bbmodel`、`.json` 模型（Bedrock geometry / Java Block&Item）与 MagicaVoxel `.vox` 体素模型。所有数据保存在本地资源库中，支持封面预览、动画播放、标签分类、批量管理与导出。

## 功能特点

- 支持 BBMODEL、JSON、VOX 模型，上传、存储、预览流程统一
- JSON 模型可在上传页单独添加贴图与 Bedrock `.animation.json` 动作文件，并即时预览
- 按「模型文件 + 贴图」内容指纹精确查重，动作文件不参与；发现相同内容时提示是否继续上传（覆盖）
- 设置中可一键重新生成全部预览图；首页卡片右键可刷新单个/选中批量的预览图
- 首页拖拽仅支持 BBMODEL / VOX；JSON 模型请点上传按钮进入专属上传页添加贴图与动作文件
- 上传页采用多模型行式暂存：每个模型一行（缩略图 + 文件信息 + 关联贴图/动作），可一次添加多个，点击底部「上传全部」后才真正入库
- 侧边栏文件夹：默认「全部文件」不可删除，文件夹支持新建、重命名、自定义颜色、删除；可把模型拖入文件夹，或选中后批量移动（仅数据库分类，不移动磁盘文件）
- 首页筛选行：按格式、是否含动画、是否有预览图、文件大小区间、上传时间区间筛选，并与标签/文件夹筛选叠加
- 卡片右键：打开详情、重命名、刷新预览图、移动到文件夹、添加标签、导出、删除
- three.js 实时预览：轨道旋转、缩放、平移、自动旋转、地板、动画播放
- 自动生成封面，并在上传/保存时记录当前视角
- 标签系统、关键字搜索、排序、标签/文件夹筛选、框选与多选批量操作
- 在卡片上按住拖动，可把源文件（支持多选）直接拖到桌面或其它应用
- 全局后台上传进度条，不阻塞列表操作
- 深色/浅色主题、皮肤色、7 种语言、自定义快捷键
- 完整的操作日志与设备信息查看
- 所有数据存储在本地，无需联网即可使用

## 支持格式

- 模型：BBMODEL（Blockbench `.bbmodel`，贴图需内嵌为 data URI）
- 模型：JSON（Bedrock geometry / Java Block&Item，需单独添加贴图；动作支持 Bedrock `.animation.json`）
- 模型：VOX（MagicaVoxel 体素模型，使用内置调色板）
- 元数据：SQLite 数据库（`imodel.db`）
- 文件存储：按 SHA256 哈希分片存储在 `models/XX/` 目录下（`XX` 为哈希前两位，`00-ff`）
- 资源库配置：`library.json` 存储资源库基本信息

## 系统要求

- Windows 10+ / macOS 10.15+ / Linux
- Node.js 18+

## 使用指南

1. 首次启动：选择“创建资源库”创建空库，或“打开资源库”选择已有库
2. 上传模型：点击右上角上传按钮进入专属上传页，可一次选择/拖入多个模型；BBMODEL / VOX 也可直接拖入模型列表
3. 补充文件：JSON 模型在上传页每一行上拖入贴图与 `.animation.json`，点击底部「上传全部」统一下发
4. 分类整理：在左侧边栏新建文件夹并设置颜色，把模型拖入文件夹，或多选后点「移动到文件夹」
5. 预览模型：双击模型卡片进入详情，调整视角、播放动画并保存封面
6. 编辑信息：在详情页修改名称、简介与标签
7. 检索管理：使用搜索、标签/格式/动画/大小/时间筛选、排序、框选与批量操作整理资源
8. 导出/拖出：右键菜单或详情页可导出模型文件夹，列表卡片可直接拖出源文件

## 开发

需要 Node.js 18+、Rust 1.87+、WebView2（Windows 10/11 自带）与 MSVC 构建工具。

```bash
npm install
npm run tauri:dev    # 启动 Tauri 开发环境
npm run tauri:build  # 打包 Windows NSIS 安装包
npm test             # 无前端测试时可用 cargo test --lib 验证数据层
```

仅调试前端时可用 `npm run dev`（Vite 1420），但需要 `npm run tauri:dev` 才能获得文件对话框、拖拽和本地存储能力。
